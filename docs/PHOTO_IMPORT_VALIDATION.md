# 사진 종목 등록 검증 — 2026-10-22

- 경로: 왼쪽 사진으로 종목 등록 → 사진 선택 → 추출·검사 → 원본 비교·선택 → 확인 후 등록.
- PNG/JPEG/WEBP, 5MB, 2천만 화소, 추출 100행 제한. OpenAI Responses API의 설정된 모델 사용, store=False. 사진은 앱 DB에 저장하지 않으며, 원본 촬영 메타데이터를 제거한 이미지로 전송한다.
- 원본에 보이는 이름·코드만 추출한다. 추정 보정·회사명 유사검색으로 등록하지 않는다. 추출 불확실, 이름/코드 불일치, 사진 내 중복, 기존 목록, KRX 목록 미확인은 등록 후보에서 제외한다.
- 서버에 보관한 검증 결과의 토큰과 선택 행만 등록 요청으로 받고 상장 목록을 재확인한다. 기존 종목은 덮어쓰지 않는다. 기존 5종목 제한은 유지한다.

## 한계

이는 제한된 검사용 이미지로 확인한 결과로, 흐린 휴대전화 촬영 사진 전체에 대한 OCR 정확도를 의미하지 않는다. 다른 정상 상장 종목으로 잘못 읽힌 경우 상장 목록 검사만으로는 검출할 수 없어 원본 대조·직접 선택을 필수로 둔다. KRX 최근 제공 목록에 없다는 사실만으로 비상장임을 단정하지 않는다. 잘못 읽힌 항목은 선명한 사진으로 다시 추출하거나 기존 종목 검색에서 직접 등록한다.
