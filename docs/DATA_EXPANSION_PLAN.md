# 금융·경제 데이터 자동 수집 확장 계획

작성일: 2026-10-22 / 상태: 설계 초안, 전체 연동 완료 아님

## 목표와 범위

보내주신 두 이미지의 전체 서비스를 연동 후보로 관리한다. 국내 상장 주식의 아침 보고서가 최종 목적이며, 미국 기업·부동산·항공·해운 자료는 관련 업종의 배경으로 연결한다. 비상장 회사를 투자 대상 종목에 추가하지 않는다.

사이트의 모든 페이지를 복제하는 작업이 아니라, 각 출처에서 보고서에 사용할 데이터셋을 정의하고 자동으로 갱신하는 구조다. 사이트마다 이용 가능한 API·계약·다운로드 범위가 다르므로 모든 사이트의 자동 수집 가능성을 아직 확정하지 않는다. 제휴나 접근 승인이 확보되지 않은 출처는 대기 상태로 남긴다.

## 접근 방식 확인 결과와 미확인 항목

- 현재 앱에서 검증된 출처: KRX 개별 종목 정보·일별 시세, DART 원문 및 RAG, 뉴스 MCP.
- 이번 구현 중 실제 응답을 확인한 항목: 한국은행 기준금리 공식 표, FRED 원/달러 CSV. 아침 보고서 전체의 실데이터·화면 검증은 아직 진행 전이다.
- 공식 데이터 접근 안내 확인: SEC API, KOSIS Open API, 한국은행 ECOS Open API, EIA Open Data.
- CME FedWatch는 공식 API가 있다. 공개 페이지는 종가형 상품을 월 25달러부터 안내한다. 현재 계약·권한이나 실제 호출 성공을 확인한 것은 아니다.
- Trading Economics는 API 구독과 키가 필요하며 비용은 기능·호출량·배포 범위에 따라 달라진다.
- MarineTraffic은 공식 API 서비스와 키 관리 절차가 있다. 이용할 상품·가격·권한은 미확인이다.
- 그 외 사이트는 API 제공·데이터 추출·재배포 가능 여부를 개별 확인해야 한다. 무료 수집 가능/불가능을 아직 단정하지 않는다.
- API가 있는 사이트도 웹 구독권과 API 이용권이 같은지 별도 확인한다.
- 이미지에 있는 사이트 이름만으로 계정 생성, 약관 동의, 유료 구독을 실행하지 않는다.

## 공통 수집 구조

출처별 수집기 → 원자료 보관 → 형식·단위·시각 정규화 → 품질 검사 → 공통 데이터 저장 → 업종/종목 연결 → LangGraph 보고서 생성 → Streamlit 미리보기.

수집은 보고서를 열 때마다 전체 사이트를 호출하는 방식이 아니다. 별도 작업으로 갱신하고 보고서는 검증된 저장본을 읽는다. 현재 API 서버 안의 요청 처리와 분리된 수집 작업자를 단계적으로 도입한다.

### 저장 구분

- 수치: SQLite로 시작하고 데이터량·동시 작업이 증가하면 PostgreSQL 전환을 검토한다. 시계열 수치 자체는 벡터 DB에 넣지 않는다.
- 공시·정책·해설: 원문 출처/해시/시점과 함께 보관하고 필요한 문단만 Qdrant에 임베딩한다.
- 금리 기대 확률, GDP 추정, 심리 지수: 확정된 실제 지표와 별도 유형으로 저장한다.
- 같은 지표를 여러 사이트에서 받으면 원출처를 대표값으로 삼고, 관측 시각·통화·단위가 같을 때만 비교한다. 다르면 평균 내지 않고 불일치로 표시한다.

### 필수 메타데이터

source_id, dataset_id, 원문 URL, 관측 기간, 발표 시각, 수집 시각, 최초 확인 시각, 수정 버전, 단위, 통화, 국가, 공식 업종 코드, 종목코드, 발행회사 코드, 연결/별도 구분, 값/본문, 수집 상태.

최초 확인 시각을 보관해야 나중에 오전 8시에 실제로 알 수 있었던 정보만으로 보고서를 재현할 수 있다. 발행일만 필터한 보고서는 엄밀한 과거 시점 검증 자료가 아니다.

### 수집 상태

연동 검토 / 신청 필요 / 개발 중 / 정상 / 신규 발표 없음 / 지연 / 실패 / 권한 만료.

수집 실패를 0이나 변동 없음으로 바꾸지 않는다. 마지막 정상 관측값과 그 날짜를 표시한다. 실패한 한 출처 때문에 전체 보고서를 중단하지 않는다.

## 종목 연결 규칙

- 공시·재무: 종목코드와 발행회사 고유번호를 정확히 연결한다.
- 시장 공통: 기준금리·환율·시장 지수를 배경으로 사용한다.
- 업종: 공식 업종과 사업보고서에 나타난 실제 사업/수출/원재료 노출 근거를 결합한다.
- 계열사: 연결 재무와 개별 회사 실적을 분리한다. 그룹명이 같다는 이유만으로 개별 기업의 호재로 처리하지 않는다.
- 예시: 반도체는 관련 수출/수요 지표, 항공은 유가/환율/항공수요, 건설은 금리/거래/착공 등. 업종명만으로 영향 방향을 확정하지 않는다.
- 미국 기관 보유 공시는 공개일 기준으로 사용한다. 보유 기준일을 당일 매매 신호로 해석하지 않는다.

## 도입 순서와 완료 조건

1. 아침 보고서 기반: KRX, DART, 뉴스, 한국은행, FRED. 실제 종목별 5거래일·뉴스 시간 경계·결측 상태·계산식 검증 완료가 기준.
2. 공식 거시·정책: FED, KOSIS, 국제 통계, 재무부/에너지/무역 자료. 각 출처에서 먼저 대표 데이터셋 1개를 연결하고 개정·발표 시각까지 검증.
3. 기업 비교·기대·상업 데이터: SEC 기반 기업/기관 정보와 데이터 상품. PER/PBR/ROE 산식·비교군·데이터 이용 범위를 확정한 뒤 연결. CME/상업 데이터 비용 승인 별도.
4. 업종 특화·부동산·대체 자료: 국내 산업/부동산 통계, 해운·항공 자료와 관련 서비스. 실제 관심 종목과 연결 가능한 지표를 우선한다.
5. 원래 목록의 남은 모든 출처: 동일한 검증 절차로 순차 편입. 연결 불가한 출처는 원인과 대안을 기록하고 원사이트 연결 완료로 표기하지 않는다.
6. 보고서 품질 확정 후 이메일: 수신자·거래일 달력·중복 발송 방지·실패 재시도·항상 켜진 실행 환경을 정한다.

각 출처 완료 기준: 원자료 실호출 성공, 단위/기간/출처 대조, 휴일·지연·실패 처리, 중복/개정 처리, 계정 권한 확인, 종목 연결 확인, 보고서에서 근거와 관측일 표시.

## 우선 필요한 정보

1. 두 이미지가 나온 원본 페이지 URL: 모든 서비스의 정확한 링크를 추출하고 비슷한 이름의 사이트를 구분하는 데 필요.
2. 유료 데이터 월 예산: 계약이 필요한 출처의 우선순위 확정용. 현재 자동 구독·결제는 하지 않음.
3. ECOS·KOSIS 등 추가 키: 데이터셋 선정 후 필요한 키만 요청. 키는 채팅에 붙이지 않고 기존 환경 파일에 저장.
4. 국내 상장 주식이라는 대상 범위는 유지. 해외 기업/부동산 데이터는 배경 자료이며 매매 대상 확장이 아님.

## 현재 구현 상태

아침 보고서 코드와 화면 초안을 추가했고 자동 테스트 167개는 통과했다. 전체 사이트 확장 계획을 먼저 정리하라는 요청에 따라 추가 연동 개발은 진행하지 않았다. 아침 보고서의 실제 종목별 생성·브라우저 확인은 아직 완료하지 않았다. 이메일 발송·자동 수집 스케줄은 설정하지 않았다.
