# 아침 보고서 연결 상태 — 2026-10-22

앱에서 종목 선택 → 아침 보고서 → 보고서 생성 · 새로고침으로 사용한다. 자동 발송은 하지 않는다.

- KRX 개별 시세: 전일까지 최근 5거래일 표시, 전 거래일 등락률, 5거래일 누적, 5일 평균 대비, 변동성·거래량 계산.
- 뉴스 MCP: 보고서 기간을 전달해 NAVER 최신 최대 1,000건을 페이지 조회. 기간 내 최대 20건 선별, 최대 5건 분석, 방향별 최대 3건 표시. Google 대체 검색은 과거 페이지 제한을 경고한다.
- DART/RAG: 기존 분석 흐름의 공시 배경 검색을 사용하며 당일 공시는 제외한다. 미저장 종목은 기사만 분석한다.
- 한국 기준금리: 한국은행 공식 공개 표.
- 환율·미국 금리 범위·S&P500·나스닥: FRED 공개 CSV, 관측일 표시. 환율은 전일 자료가 아닐 수 있다.
- 미국 정책 발표: FED 공식 통화정책 RSS 최근 3건, 원제목과 발표시각·원문 링크. 종목별 방향 추정은 하지 않는다.

## 실제 확인

로컬 관심 목록 삼성전자·SK하이닉스를 비어 있던 Docker 목록에 등록했다. 기존 분석 이력은 삭제하지 않았다.
두 종목 보고서 생성·저장, 시세 기준일 10월 21일, 공식 경제 지표 6개와 FED 발표 조회를 확인했다.
SK하이닉스 긍정 3건·미완료 1건, 삼성전자 미완료 2건으로 방향별 표시는 0건이었다. 삼성전자는 검색 상한에 도달했다.
이는 연결 검증이며 의미 판단 정확도 검증 통과를 뜻하지 않는다. 지분 매각 기사의 매출 기회 해석 등 기존 판단 품질 문제는 남아 있다.
앱의 아침 보고서 화면 표시 확인. 테스트 170개 통과. 자세한 결과는 output/morning-report-validation.html.

## 추가 필요

- KRX 코스피·코스닥 지수 일별 시세 API: 현재 키로 권한 오류. 개별 종목 API와 별도 승인 필요.
- ECOS_API_KEY 미등록: ECOS 직접 연동은 아직 구현·검증하지 않았다. 한국은행 공개 표와 FRED를 사용 중이다.
- 발표 일정, 업종 PER/PBR/ROE, 이메일 예약 발송은 다음 범위다.
- 오전 8시 당시 수집본을 저장한 보고서가 아니라 발행시각을 제한한 현재 자료 미리보기다.
